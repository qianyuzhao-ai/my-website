Over the past year, I handed more and more of my design workflow to agents: tidying Figma files, scaffolding UI components, and auditing implementations against design tokens. Output velocity jumped, yet a sharper question surfaced—when generation speed far outpaces review speed, where does a designer's real value live?

## Draw the Boundary First

My approach splits every project into two buckets: **generation** and **judgment**. Generation work—turning structured mocks into component skeletons or batch-updating copy—goes to agents. Judgment work—information hierarchy, interaction pacing, and what to leave out—stays strictly human.

> Tools finish the work; designers decide what is worth building.

## A Concrete Example

The initial homepage card grid was generated by an agent straight from Figma. Structurally it matched, yet the mobile reading order blindly mirrored desktop. Extracting content priority into a deterministic sorting rule made both mobile and desktop hold together:

```ts
function mobileOrder(id) {
  const top = highlighted[id];
  return [...top, ...rest(top)];
}
```

## My Workflow Today

- Start mobile-first, expand to tablet, then finish desktop
- Leave a clean, revertible commit after every coherent step
- Ask the agent to explain its reasoning, not merely execute edits
